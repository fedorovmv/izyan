# Метрики, трасировка, аудит

- Тайминги каждого state пишутся в кейс (`timings:` строка в выводе и
  отчёт) — новые стадии/тяжёлые операции замеряй.
- `llm_calls` инкрементируется на каждый вызов; бюджет `MaxLLMCalls`
  уважается — при исчерпании честный limitation.
- `tool_executions` + `ToolVersion` аудит — exec-инструменты и
  версии toolchain пишутся в EvidenceGraph; reproducibility: тот же
  вход → тот же детерминистический выход.
- Limitations — первоклассные граждане: каждое упрощение анализа
  записывается в claim/case limitations и видно в отчёте, а не
  теряется в логах.
- Отчёт показывает историю доказательств: demoted-claims отображают
  `falsifier / VERIFIED (demoted)`, не только финальный результат.
- Прогресс длинных операций — на stderr, отчёты — в файлы; stdout
  чистый для пайплайна.
