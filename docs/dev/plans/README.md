# Временные планы реализации (Implementation Plans)

Этот каталог предназначен для пошаговых планов реализации (TDD-чек-листов), создаваемых скиллом `writing-plans` на время выполнения задач.

## Правило жизненного цикла

1. План задачи создаётся в ветке фичи: `docs/dev/plans/YYYY-MM-DD-<feature>.md`.
2. В процессе разработки агент выполняет шаги по чек-листу (`subagent-driven-development` / `executing-plans`).
3. **После завершения работы, прохождения тестов и приёмки задачи — файл плана удаляется**.

Каталог не предназначен для хранения постоянных документов. Стратегические планы развития живут в [`docs/dev/roadmaps/`](../roadmaps/), а дизайн-спецификации реализованных фич архивируются в [`docs/dev/history/features/`](../history/features/).
