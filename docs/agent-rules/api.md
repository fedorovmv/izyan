# API и интерфейсы

- CLI — публичная поверхность: субкоманды `analyze`, `scan`, `eval`,
  `remediate`, `knowledge`; новые флаги — с разумными дефолтами и документацией в
  usage; обратная совместимость флагов не ломается без причины.
- `report.json` / `case.json` — персистентные схемы: новые поля
  `omitempty`, существующие не переименовываются (рестарт кейса читает
  старые файлы).
- Экспорты и отчёты: `report.md` (русская локализация, обязательный
  раздел `## Резюме` во главе отчёта), `report.en.md` (английская
  локализация), OpenVEX, CycloneDX, tracker_comment — строгая валидация
  против схемы формата, не «почти VEX».
- Входные контракты generic: `--vuln-file` (OSV JSON), `--ticket`
  (generic tracker JSON), корпуса `eval/corpus-real.json` и
  `eval/live-corpus.json` — env-экспансия в путях, относительные
  пути резолвятся от файла корпуса.
- Ошибки CLI — понятные сообщения и корректный exit code; usage на
  stderr при неверных флагах.
